# Repository Truth Protocol

Evidence classifications:
- CONFIRMED — directly observed in source/configuration.
- DOCUMENTED — stated by documentation only.
- INFERRED — reasonable conclusion not directly proven.
- POTENTIAL — depends on runtime/configuration/reachability.
- NOT VERIFIED — static review cannot establish the property.
- CONFLICT — sources disagree.

GitHub source and actual implementation outrank assumptions, generated plans, or AI suggestions. Never present an inference as a confirmed fact.
