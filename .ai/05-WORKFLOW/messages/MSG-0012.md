## 4. Defect Discovered and Resolved During Testing

PostgreSQL threw error `42804` (`column "role" is of type user_role but expression is of type text`) when inserting into `public.profiles` because `profiles.role` uses the custom enum type `public.user_role`. 
- **Fix:** Added `v_invitation.role::public.user_role` in `supabase/migrations/045_bind_invitation_rpc.sql`.
- **Commit:** `6b54786` (`fix(db): cast v_invitation.role to public.user_role enum in RPC`).
