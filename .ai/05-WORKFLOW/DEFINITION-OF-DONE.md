# Definition of Done

- Acceptance criteria pass.
- Relevant checks actually run and exact results are recorded.
- Authorization is enforced at the operation boundary.
- Tenant isolation is verified when relevant.
- RLS is reviewed when relevant.
- Privileged access is justified and tested.
- No secrets or security bypasses.
- No unrelated changes.
- Implementation report is complete.
- ChatGPT architecture/security review is complete.
- Human approval exists wherever required.
