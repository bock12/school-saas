# Escalation Policy

Use `ARCHITECTURAL_ESCALATION` when a task requires changes to authentication, authorization, RBAC, tenant isolation, RLS, schema, service-role access, direct PostgreSQL/auth.users access, dependencies, public/private API contracts, or destructive operations beyond approved scope.

Required: Task ID, evidence/file paths, problem, security/business impact, options, recommendation, decision required, status `BLOCKED — ARCHITECTURAL DECISION REQUIRED`.
