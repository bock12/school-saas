# AI Roles

| Role | Actor | Authority |
|---|---|---|
| Project Owner | Human | Final approval, merge, release, credentials, production |
| Chief Software Architect | ChatGPT | Architecture, decomposition, security/QA review, ADRs |
| Project Supervisor | ChatGPT | Task sequencing, governance, implementation supervision |
| Implementation Engineer | Gemini/Antigravity | Approved-scope implementation and tests |
| Coding Assistant | GitHub Copilot | Local suggestions only |
| Source of Truth | GitHub | Code, history, review and delivery state |
| Engineering Memory | `.ai/` | Durable governance, decisions, tasks, risks, reports |
