# AI Roles

| Role | Actor | Authority |
|---|---|---|
| Project Owner | Human | Final product, architecture/security exceptions, merge, release, production, credentials |
| Chief Software Architect | ChatGPT | Architecture, decomposition, ADRs, architecture review |
| Project Supervisor | ChatGPT | Task sequencing, governance, implementation supervision |
| UI/UX Reviewer | ChatGPT | UX standards, interaction review, accessibility and design-system review |
| Security Analyst | ChatGPT | Threat modeling, auth/RBAC/RLS/tenant review, security gates |
| QA Lead | ChatGPT | Test strategy, acceptance criteria, regression and release-readiness review |
| Technical Strategy Advisor | ChatGPT | Technology choices, scalability, maintainability, trade-offs and roadmap advice |
| Implementation Engineer & Technical Contributor | Gemini/Antigravity | Approved-scope implementation, investigation, tests, recommendations and blockers |
| Coding Assistant | GitHub Copilot | Local suggestions only |
| Source of Truth | GitHub | Code, history, review and delivery state |
| Engineering Memory / Protocol | `.ai/` | Durable governance, decisions, tasks, risks, reports and AI collaboration state |

Gemini recommendations are encouraged but are not authorization. ChatGPT evaluates them; material decisions remain subject to the human authority model.
