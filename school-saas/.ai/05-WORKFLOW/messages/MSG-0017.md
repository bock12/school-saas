1. **BLOCKER 1 (VP & Exam Officer Base-Role Contradiction):**
   - Base roles are strictly additive: an assignment can NEVER remove permissions granted by a base role.
   - Principal: Base Role = `school_admin` (intrinsic executive authority).
   - Vice Principal: Base Role = `teacher`, Functional Assignment = `Vice Principal` (CANNOT approve or publish).
   - Exam Officer: Base Role = `teacher`, Functional Assignment = `Exam Officer` (CANNOT approve or publish).
   - Prohibited: VP and Exam Officer cannot be classified as `school_admin`.
2. **BLOCKER 2 (Principal vs School Admin Authority):**
   - Defined `school_admin` as an administrative security role representing **institutional executive / Principal-level authority**.

3. **BLOCKER 3 (Authoritative VP Persistence Model):**
