# AI Collaboration Playbook
## School Management System

This playbook establishes a controlled workflow for using multiple AI coding tools on the same repository.

### Recommended operating model
- **Codex / ChatGPT:** Chief Software Architect, Project Supervisor, UI/UX Reviewer, Security Analyst, QA/Quality Gatekeeper.
- **Gemini in Antigravity:** Senior Software Engineer and Implementation Lead.
- **GitHub Copilot in VS Code:** Developer assistant for inline completion, refactoring, boilerplate, and focused coding support.
- **Human developer:** Final authority. Reviews plans, approves risky changes, runs the application, and controls merges/deployments.

### Core rule
The shared Markdown files are the communication layer. AI agents must read the relevant project instructions before making changes and must record decisions, tasks, implementation results, risks, and review outcomes.

See `01-IMPLEMENTATION-PLAN.md` for the complete setup sequence.
