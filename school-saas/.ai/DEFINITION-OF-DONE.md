# Definition of Done

A task is complete only when applicable items below are satisfied.

## Functional
- [ ] Requirement implemented
- [ ] Edge cases handled
- [ ] Error states handled
- [ ] Permissions enforced

## Technical
- [ ] Types pass
- [ ] Lint passes
- [ ] Relevant tests pass
- [ ] Build passes
- [ ] No unexplained console/runtime errors
- [ ] No unnecessary duplication

## Security
- [ ] Authorization reviewed
- [ ] Tenant isolation reviewed where applicable
- [ ] No secrets exposed
- [ ] Input validation considered

## UI/UX
- [ ] Responsive
- [ ] Accessible
- [ ] Loading state
- [ ] Empty state
- [ ] Error state
- [ ] Consistent with existing design

## Documentation
- [ ] Implementation report completed
- [ ] Architecture decision recorded if needed
- [ ] Changelog updated if user-visible
